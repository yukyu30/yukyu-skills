# yukyu-skills

Claude Code 用の marketplace です。

```
/plugin marketplace add yukyu30/yukyu-skills
/plugin install blog-writing@yukyu-skills
/plugin install stop-ai-slop-jp@yukyu-skills
/plugin install pstack@yukyu-skills
```

| plugin | 種別 | 内容 |
| --- | --- | --- |
| `blog-writing` | 同梱 | `write-blog-article` / `article-review` / `tech-review` / `japanese-tech-blog-writing` |
| `stop-ai-slop-jp` | 外部参照 | AI臭のある日本語を直す。上流 repo を直接参照 |
| `pstack` | 外部参照 | [cursor/plugins](https://github.com/cursor/plugins/tree/main/pstack) の agent workflow 集 |

出典は [NOTICE.md](./NOTICE.md) を参照してください。
